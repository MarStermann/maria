# SEO Checklist

## Technical

- Use server-rendered or statically generated content for crawlable pages.
- Keep `robots` and `sitemap` aligned with real routes.
- Keep `NEXT_PUBLIC_ALLOW_INDEXING=false` until launch content is approved.
- Use one unique H1 per page.
- Add canonical URLs using `NEXT_PUBLIC_SITE_URL`.
- Add descriptive titles and meta descriptions for every indexable page.
- Keep Open Graph images available and relevant.

## Local SEO

- Use consistent practice name, address, phone, and opening hours once confirmed.
- Build pages around local search intent only when the city/location is real.
- Do not publish placeholder address data.
- Use `LocalBusiness` structured data conservatively.

## Service SEO

- One service page should answer one intent.
- Add internal links between service index, individual service pages, contact, and first-visit content.
- FAQ content should answer real pre-appointment questions.
- Avoid symptom lists that imply treatment promises.

## Performance

- Prefer static assets and optimized images.
- Avoid heavy animation and client-only content for core copy.
- Keep layout stable on mobile.
