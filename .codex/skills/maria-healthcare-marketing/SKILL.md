# Maria Healthcare Marketing

## Workflow

1. Clarify the page goal: trust, local discovery, service education, or appointment request.
2. Keep claims conservative and verifiable. Never invent outcomes, credentials, reviews, addresses, or medical indications.
3. Build each page around one search intent and one primary conversion action.
4. Prefer German copy unless the user asks otherwise.
5. Use real German umlauts and `ß` in visible German copy. Keep ASCII transliteration only for slugs, URLs, code identifiers, file names, env vars, and other technical values.
6. Treat legal, medical, privacy, and analytics decisions as review-required before launch.

## Required References

- Read `references/content-rules.md` before drafting or editing patient-facing copy.
- Read `references/seo-checklist.md` before changing metadata, routes, sitemap, robots, structured data, or CMS SEO fields.

## Output Expectations

- Keep suggestions practical and implementation-ready.
- Flag placeholders and launch blockers clearly.
- Prefer CMS-ready field names and reusable content structures.
- Avoid broad marketing fluff; write specific, calm, local, credible copy.
